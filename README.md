# Echo 实时多语言会议同传系统

Echo 是一套面向国际会议、学术论坛、跨语言研讨等场景的实时多语言同声传译与互动平台。系统基于 WebSocket 实现端到端实时通信，将演讲者的语音实时转化为多语言字幕，观众可自主选择观看语言，实现无障碍跨语言交流。

## 核心功能

演讲者通过浏览器麦克风采集音频，实时传输至服务端，由 AI 流式语音识别引擎进行实时转写。识别结果按语义断句逐句落库，并同步调用大语言模型进行多目标语言翻译，翻译字幕实时推送至各语言频道的观众端展示，端到端延迟控制在秒级。系统支持演讲者、观众、管理员三类角色协同：演讲者负责发言与语言切换，可选择多种目标翻译语言；观众通过二维码或链接加入房间，自主选择字幕语言频道；管理员负责创建会议房间、管理演讲者配置、审核互动问题及控制会议生命周期。

系统内置实时互动问答模块，观众可提交问题，管理员审核通过后即时推送至全体参会者，支持投票、置顶、高亮等交互操作。会议结束后，系统可基于全部已识别字幕，由 AI 自动归集整理生成结构化发言稿，支持原文与中文对照，供会后存档发布。

## 技术特性

前端采用 React + TypeScript + Vite 构建，响应式适配桌面与移动端，支持 PWA 安装；后端采用 Node.js + Express + Socket.IO，数据持久化基于 PostgreSQL。语音识别连接具备自动重连、僵尸连接检测、静音兜底切分等容错机制；翻译引擎支持多级降级保障服务连续性；会议房间支持延迟回收，演讲者短暂断线后可无缝重连续讲。
